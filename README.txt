SMART ZOMBIES — Minecraft Forge 1.20.1

VERSÃO:
- Minecraft Java 1.20.1
- Forge 47.4.26
- Java 17

O QUE O MOD FAZ:
- Zumbis procuram jogadores próximos de forma mais ativa.
- Podem pegar itens úteis que estejam no chão.
- Podem equipar ferramentas encontradas.
- Podem usar picareta de madeira quando precisam abrir um caminho.
- Podem quebrar alguns blocos naturais/construídos para alcançar o jogador.
- Podem usar blocos coletados na mão secundária.
- Podem construir pequenas pontes sobre buracos.
- Podem criar degraus/caminhos quando existe diferença de altura.
- A IA é limitada para evitar destruir o mundo inteiro.

INSTALAÇÃO:
1. Instale Forge 1.20.1 no SKLauncher.
2. Use Java 17 para a instância 1.20.1.
3. Compile o projeto com:
   gradlew build
4. O arquivo ficará em:
   build/libs/smartzombies-1.0.0.jar
5. Coloque o JAR em:
   .minecraft/mods

IMPORTANTE:
Este pacote é o projeto-fonte do mod. O ambiente de geração não possui o conjunto de dependências/MDK do Forge disponível localmente para compilar o JAR aqui.
Ao abrir o projeto em um computador com internet, o Gradle baixa automaticamente Forge 47.4.26 e gera o JAR.
